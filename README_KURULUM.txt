METIN2 BALIK BOTU - WINDOWS 10 64-BIT

Bu paket kaynak kodu + GitHub Actions derleme ayaridir. Hazir EXE degildir.
Bu oturumda Windows derleyicisi bulunmadigi icin dogrudan EXE uretemedim.

EXE'yi Python kurmadan almak:
1) github.com adresinde hesap ac / giris yap.
2) New repository ile bos bir repo olustur.
3) Bu ZIP'in icindeki tum dosyalari repo'ya yukle (klasor yapisini koru).
4) GitHub reposunda Actions sekmesine gir.
5) "Build Windows EXE" akisina tikla, "Run workflow" sec.
6) Islem bitince alttaki Artifacts bolumunden
   Metin2BalikBot-Windows10-x64 dosyasini indir.
7) ZIP'i acip Metin2BalikBot.exe dosyasini calistir.

Kullanim:
- Oyunu pencere modunda ac ve oyunu one getir.
- Botu ac, yem kutusunu sec; 3 saniye icinde fareyi yem ikonunun ortasina getir.
- Baslat'a bas. F8 veya Durdur ile kapat.
- Ilk testte karakterin basinda dur; simge algilama esigi/olcek sunucuya gore ayar isteyebilir.

Dikkat:
- Bu bir ilk prototiptir, oyun istemcisi/sunucu farklarinda test ve ayar gerekir.
- Simge sablonu gonderdigin ekran goruntusunden kesilmistir.
- Bot, her dongunun basinda secilen koordinata sag tiklar.
- Oyunun ve sunucunun otomasyon kurallarini kontrol et.
